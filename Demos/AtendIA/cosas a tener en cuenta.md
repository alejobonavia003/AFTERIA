El MVP tiene que incluir una interfaz ultra rápida (quizás desde un celular o tablet) para que el cajero apague o prenda productos con un solo toque. La IA debe consultar esa base de datos (idealmente en PostgreSQL para asegurar la integridad transaccional) antes de confirmar cualquier pedido.

Priorizar el desarrollo rápido del producto mínimo viable enfocándose **únicamente en WhatsApp** para la primera versión

El sistema necesita alertas visuales muy claras (colores fuertes, tipografía grande) e incluso alertas sonoras distintivas para que el cajero sepa que un chat requiere intervención humana urgente.
