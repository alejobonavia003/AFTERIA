
# Priorización

🟢 Muy factible | 🟡 Factible con riesgos | 🔴 Escasa factibilidad

| Producto | Problema que resuelve | Cliente objetivo | Factibilidad |
|---|---|---|:---:|
| Agente IA para atención al cliente | Reduce llamadas repetitivas, automatiza turnos y mejora la atención | Talleres pequeños y medianos | 🟢 |
| Plataforma inteligente de presupuestos | Disminuye el tiempo necesario para cotizar reparaciones y buscar repuestos | Talleres pequeños y medianos | 🟢 |
| Historial inteligente del vehículo | Centraliza toda la información del cliente y facilita futuras reparaciones | Talleres de cualquier tamaño | 🟢 |
| Dashboard operativo | Permite medir productividad, ocupación y rentabilidad del taller | Dueños y gerentes | 🟡 |
| Sistema de mantenimiento preventivo | Incrementa la fidelización y el retorno de clientes | Talleres con cartera estable de clientes | 🟡 |
| Aplicación de inspecciones digitales | Mejora la comunicación con el cliente y documenta el trabajo realizado | Talleres medianos y grandes | 🔴 |

---

🟢 = problema ampliamente documentado, frecuente en talleres pequeños y medianos, con espacio para diferenciarse mediante IA, automatización o integración con WhatsApp.

🟡 = problema validado, aunque suele requerir integración con software de gestión existente o enfrenta competencia moderada.

🔴 = funcionalidad ampliamente ofrecida por plataformas consolidadas como Shopmonkey, Tekmetric, AutoLeap o AutoServe1, dificultando competir como producto independiente.
