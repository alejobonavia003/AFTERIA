````
### Ejemplo: Restaurante

Durante el análisis podemos detectar diferentes problemas:

```text
Restaurantes
│
├── Muchísimos mensajes
│        │
│        └── IA para WhatsApp
│
├── Mala gestión de reservas
│        │
│        └── Sistema de reservas
│
├── Poco control del stock
│        │
│        └── Sistema de inventario
│
├── No conocen sus métricas
│        │
│        └── Dashboard
│
└── Mala comunicación cocina-caja
         │
         └── Sistema de comandas
````

Estos problemas se transforman en oportunidades de producto:

| Producto              | Problema que resuelve                                                  | Cliente objetivo                     | Potencial |
| --------------------- | ---------------------------------------------------------------------- | ------------------------------------ | --------- |
| IA para WhatsApp      | Gran cantidad de consultas y pedidos que requieren atención manual     | Restaurantes con delivery            | Alto      |
| Sistema de reservas   | Mala gestión y organización de reservas y mesas                        | Restaurantes con salón               | Medio     |
| Sistema de inventario | Poco control del stock, pérdidas y desperdicio de insumos              | Restaurantes medianos/grandes        | Alto      |
| Dashboard de métricas | Falta de información sobre ventas, productos y rendimiento del negocio | Restaurantes pequeños/medianos       | Medio     |
| Sistema de comandas   | Mala comunicación entre salón, caja y cocina                           | Restaurantes con atención presencial | Alto      |
