**Objetivo**

Investigar distintos sectores comerciales para identificar problemas frecuentes, costosos y repetitivos que puedan resolverse mediante productos de software estandarizados. 
El propósito final es construir un catálogo de sistemas, automatizaciones e integraciones que puedan desarrollarse una vez y comercializarse a múltiples empresas del mismo rubro.

¿Qué productos de software podemos desarrollar una sola vez y vender muchas veces?
